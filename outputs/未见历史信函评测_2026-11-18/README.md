# 未见历史信函：100 万像素配对评测

用两封没有出现在既有开发或评测清单里的真实信函测试标题优先复读：美国国家档案馆的 [Wells-Barnett 致 Wilson](https://www.archives.gov/college-park/highlights/ida-wells-letter)（NAID 7455575）和 [Robinson 致 Eisenhower，第一页](https://www.archives.gov/exhibits/featured-documents/jackie-robinson)（NAID 186627）。前者字迹褪色、居中花体信头、多个收件戳；后者有较清晰的靠左打字正文、居中日期及底部收件戳。使用官网展览原始 JPEG，分别为 938×1200 和 764×990；这是公开展览版本，分辨率低于此前长边 2400 像素的开发件，未插值放大。

[冻结协议](protocol.json)在实跑前记录了来源网址、手工真值、图像原始坐标和未见依据，并[登记摘要](frozen.sha256)锁定两份输入和原有策略代码。先选件，人工读图标注，再打开 OCR；两份扫描均保留。共 6 个联合题，同时查日期和信头或正文。每题分别做单页和两页检索；两页时另一个信函充当干扰页。两策略同为 100 万像素、最多四个印章候选窗口；预览图与 OCR 输入均计费。每个字段要求页号正确、IoU ≥ 0.30、标注框覆盖 ≥ 48%；两字段都通过且返回 `both_located` 才算联合通过。

| 指标 | 旧跨页策略 | 标题优先复读 |
|---|---:|---:|
| 日期字段 | 4/12 | 4/12 |
| 信头或正文 | 8/12 | 8/12 |
| 联合 | 4/12 | 4/12 |
| 每题平均总像素 | 684,018 | 684,018 |
| 在边窗先确认查询日期 | 0/12 | 0/12 |
| 标题复读执行次数 | 0 | 0 |

**独立样本未观察到收益。** 四次联合通过都来自 Robinson 页的同一处居中发信日，且是全局回退读到的；两个指定收件戳都没找到。因为当前实现等到边窗确认日期才启动正文横带和标题复读，这组样本一次也没有覆盖新分支。Wells 页发信日是全文拼写 `April`，冻结日期匹配器只支持月份缩写或 ISO，是本次设计之外的另一处限制。这个结果提示应优先覆盖水平日期及底部戳记，再扩充“先找到日期、正文仍缺失”的冻结场景，才能检验标题排序本身。6 道题×2 条件只来自两份档案，不能把 12 个条件当成独立文档。

详细输出：[逐字段与像素](rows.tsv) · [原始 OCR 和调度轨迹](results.json)。来源图片总下载 185,722 字节，无新增模型或付费 API。

从本目录复跑：

