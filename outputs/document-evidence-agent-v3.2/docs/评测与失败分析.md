# 评测与失败分析

## 评测协议

- 每道题给固定顺序的候选页、一到两个锚点和预算。系统只收到页面与任务参数。公开 PDF 模式另允许使用源文件文字层定位候选，候选框只用于选择实际 OCR 的区域。
- 正例严格通过需要答案正确，且每个锚点及对应数字来自标注页。每个框分别检查 IoU ≥ 0.30、覆盖标注框面积 ≥ 48%。猜对数值而页码或框错了，计入答案正确但证据错误。
- 负例包括零证据和只存在一个锚点。单独记录错误作答、错误引用及实际找回的证据数。`partial` 和 `unresolved` 都只说明当前读取范围内证据不足。
- 每次 OCR 计实际宽乘高，包括失败的裁剪和整页扫描。同一次运行内，同页同裁剪同分辨率只计一次。像素和调用数在每个预算内分别计算，平均值包含正例和负例。
- 合成集按文档组分开。公开 PDF 与纯图像集使用相同的标注任务，PDF 条件比较时三种策略使用相同原件和渲染。公开集沿用 2.0 的五份来源。工程迭代中查看过这些版式和结果，公开集是回归样本，保留新来源作为独立泛化验证。

## 公开 PDF

5 份公开文件，20 张唯一页面，5 个候选页组，39 道任务，其中 34 道正例。21 道正例有两个字段，17 道确实跨页。每格为严格通过题数。像素数是 39 道任务的平均值。

| 像素预算 | PDF 定位＋图像核验 | 整页均分 | 纯图像预留核验 | 混合策略 / 均分平均像素 |
| --- | ---: | ---: | ---: | ---: |
| 160 万 | 26/34 | 9/34 | 2/34 | 45.95 万 / 153.49 万 |
| 260 万 | 28/34 | 15/34 | 13/34 | 67.95 万 / 237.99 万 |
| 400 万 | 28/34 | 21/34 | 15/34 | 98.61 万 / 343.32 万 |

主预算下，两个字段均正确的题数是 19/21、7/21、6/21，分别对应上表三种策略。只看跨页题，严格通过数依次是 15/17、6/17、5/17。混合策略平均少读 71.4% 的 OCR 像素，平均调用 4.051 次，整页均分 4.769 次。三种策略在 5 道负例均无完整作答。这组结果同时反映 PDF 文字层可用、单行裁剪与按需 OCR 的效果。成本口径只含送入 OCR 的图像面积。PDF 解析、整页渲染与预览另外发生，端到端吞吐需另外测量。

## 纯图像

| 260 万预算 | 预留核验 | 整页均分 | 学习评分 | 启发式裁剪 |
| --- | ---: | ---: | ---: | ---: |
| 合成留出集 | 67/70 | 63/70 | 45/70 | 47/70 |
| 同一批公开页转成图像 | 14/34 | 14/34 | 13/34 | 12/34 |

合成留出集有 10 个文档组、60 页、90 道任务。主预算下，预留核验平均读 197.9 万像素，整页均分为 212.5 万。调用均值是 7.00 和 4.91 次。按文档组重抽样 4,000 次，严格通过率差为 +5.7 个百分点，区间 [−1.4, +12.9]。在 160 万预算下，预留核验 24/70，整页均分 30/70。公开图像集在 400 万预算下，整页均分 21/34，预留核验 16/34。

动作评分器用真实 OCR 动作的通过标签训练，包含 2,097 个训练动作和 915 个开发动作。主预算下在合成留出集通过 45/70，启发式裁剪为 47/70，差的按组区间为 [−10.0, +2.9] 个百分点。公开图像上的 13/34 也低于整页均分的 14/34。保留训练入口用于分析候选特征和分布变化，默认选择 PDF 混合调度。

## 看具体失败

| 任务 | 主预算下混合策略输出 | 对应的代码和标注 |
| --- | --- | --- |
| 照明示例功率 | 文字层找到候选，同行 OCR 没有读出可用的锚点和数值，返回 `unresolved` | `doe-power`。检查标签背景和裁剪中的字号 |
| 年度能源成本 | 输出 `1.08`，但数字框和标注框的重合不足，严格评分判失败 | `doe-cost`。在结果中对照数值框与原件坐标 |
| 问卷编号 | 两个文字层锚点均无候选，纯图像回退也未命中 | `census-people`。相似页含相同模板与不同编号 |
| 等高距和海拔示例 | 只返回等高距证据，比较结果为空 | `usgs-elevation`。检查数字和图例标题是否被切成不同 OCR 行 |
| NOAA 反白标题 | 单行 OCR 在深色底上失败。按局部灰度判断并反转后，在同一候选区域读出标题 | `mixed-cross-source`。反转规则来自此处诊断，应在独立深色版式上复测 |

英文锚点、同行数字和已统一单位是当前任务契约。跨行表格关联、扫描噪声和重复标签仍需专门样本。现有结果也不覆盖单批 24 页的吞吐压测。
