# 3.1 设计与实验

## 要解决的错误

例如两份设备记录都有 Reserve load，第一页 300，第二页 700。问题只给 Reserve load 时，首次命中会产生一个表面合法、来源范围不明确的答案。3.1 把已索引的各处候选核验后交给字段判定器，区分同值、异值和未读完。

## 数据流

任务 JSON → 参数与字段页面范围校验 → PDF 候选坐标 → 轮流读取各字段候选 → 原文 OCR 证据 → 字段状态判定 → 计算或返回待核对证据。

没有文字候选的字段使用剩余预算走纯图像路径。PDF 文字层提供位置，数字来源为 OCR。原始 OCR 词与框保留在证据中，答案和字段判定都引用账本里的实际观察。

## 模块与设计取舍

**task.py** 接受 pages 列表，field_matches 在每次提取前校验来源页。限制作用于通用证据提取，因此命令行、工作台和基线策略均能遵守。scheduler.run 会在付费读取前拒绝未知页面 ID。

**audit.py** 维护各候选的 unread、unreadable、no_numeric、read 状态。每轮先让各字段读取一个候选，防止第一个字段占用全部预算。读到精确锚点但词窗内没有数字的候选记为 no_numeric。匹配到数字后记录证据，最后对同一字段的值去重。多个值导致 conflict，单值但仍有未处理候选导致 needs_review。结果中的 field_assessments 保留各值、各页证据及未读数量。

这种处理可以避免观察到冲突后直接作答，但一次 OCR 仍可能把数字读错。单行词窗外的值不会被提取。预算、OCR 质量和候选索引完整性共同决定结论的可靠范围。

**pdf_index.py** 限制词边界，避免把一个完整词的子串视作锚点。索引额外保留一个候选作为截断信号，避免把上限内的同值误认为已经遍历全文。图像回退的 scope 明确为 observed_image_regions。

**reader.py** 对每次工作进程交互设置 45 秒超时，覆盖写入和等待响应。到期终止该进程，当前请求返回错误，后续请求创建独立进程。故障测试启动实际阻塞子进程，并验证退出和重复清理。失败请求不产生答案，其部分工作不作为成功运行账本返回。

## 同预算实验

新重复字段集用固定种子 61583 生成 12 份真正的双页 PDF，字号、字体和位置变化，8 份异值、4 份同值。评测走 PDF 渲染与真实 OCR。每份测试未限定页和限定第二页两种输入，再分别运行 hybrid 与 audited，共 48 条轨迹。

| 输入 | 策略 | 符合预期 | 平均 OCR 像素 |
| --- | --- | --- | --- |
| 两页同名字段 | hybrid | 4/12 | 53,311 |
| 两页同名字段 | audited | 12/12 | 106,622 |
| 字段限定第二页 | hybrid | 12/12 | 106,622 |
| 字段限定第二页 | audited | 12/12 | 53,311 |

这里的成功包括正确拒绝冲突。生成器在 tools/build_conflict_fixtures.py，重建需要额外安装 reportlab，运行已打包样例无需该依赖。该组样例用于验证具体工程错误，规模不足以估计真实文档错误率。

公开 PDF 回归同为 260 万像素。audited 严格通过 26/34，hybrid 28/34，uniform 15/34。audited 平均 401,667 OCR 像素、2.718 次调用，hybrid 为 679,018、4.026 次。平均成本包含 39 题，5 题负例两者均未错误作答。新策略在部分候选不可读时减少后续搜索，因此更低平均开销伴随漏答。应同时看逐题失败，不能只按均值评价策略。

## 学习工单

**工单 A，重复记录。** 运行 README 的两个命令，找出字段状态变化、两处候选的 value_box、最终接受页和累计像素。练习将 scoped-task.json 的 pages 改为不存在的 ID。参考结果是读取前报错。再把范围扩大为两页，参考结果恢复 conflict。

**工单 B，故障与证据。** 阅读 tests/test_reader_failure.py，解释 Timer 为什么必须在 finally 中取消并等待结束。参考答案是防止旧请求的计时器在新工作开始后杀死进程。阅读 test_audit.py 的页面顺序测试，解释为什么状态应保持一致。参考答案是重复字段的异值集合与遍历先后无关。

**独立实验。** 新建一批业务含义明确的文档，先固定标注和页范围，再改策略。报告正确作答、错误作答、待复核、缺失证据、像素与总耗时。现有公开资料参与过调试，新增独立来源的结果才可检验泛化。部署并发、单位换算和跨行表格需要各自的任务与验收数据。
