# 3.2 纯图像评测

3.1 把大部分首轮像素均摊到整页。正文优先策略 scan-audit 延用同一像素分配，把首轮区域改为左右各内缩 8%、上下各内缩 6%。典型页面的字符线性采样密度因此约提高 16%。局部补读与整页补读沿用原有调度，实际送给 OCR 的像素全部计费。工作台可选择「候选核验＋正文优先」，CLI 可指定 --strategy scan-audit，默认仍使用 audited。

## 数据与复现

独立集取自工作区已有的三份英文论文，文件和 SHA-256 见 data/heldout/manifest.json。DocAttriBench 来源为 visual-evidence-acquisition/work/document/dab.pdf，VELD-QA 来自同目录 veld.pdf，Discriminative Visual Process Rewards 来自 multimodal-adaptive-reasoning/work/evidence/direction-scan/discprm-pmlr.pdf。这三份文档此前未进入本项目开发集。运行评测时关闭 PDF 文字索引，只向策略提供页面图像。原始文字层仅用于生成短语和坐标标注。按各页正文半栏取不同位置的唯一短语，冻结 21 个单证据任务和 8 个跨页双证据任务。双证据题复用部分短语，因此统计以题为描述单位，题目并非独立同分布。

项目目录运行，Python 须能导入 requirements.txt 中的依赖。已有清单可以直接评测，只有重建标注才需要 pdfplumber。

~~~sh
python3 -B tools/eval_scan.py --output results/heldout-replay.json
sh run.sh benchmark --split external --strategy audited scan-audit --budget 2600000 --output results/images-replay.json
sh run.sh benchmark --split external --input pdf --strategy audited scan-audit --budget 2600000 --output results/pdf-replay.json
sh run.sh test
~~~

## 性能与代价

同一预算使用相同渲染和答案，严格通过需要答案、引用页和原文框均正确。

| 数据 | 像素上限 | 3.1 严格通过 | 正文优先严格通过 | 平均 OCR 像素，旧 → 新 |
| --- | ---: | ---: | ---: | ---: |
| 独立论文纯图像 | 160 万 | 6/29 | 16/29 | 1,424,796 → 1,299,456 |
| 独立论文纯图像 | 260 万 | 21/29 | 20/29 | 1,792,097 → 1,535,674 |
| 原公开集纯图像 | 260 万 | 13/34 | 19/34 | 2,085,201 → 1,929,342 |
| 原公开集保留 PDF 索引 | 260 万 | 26/34 | 26/34 | 401,667 → 401,666 |

公开集的平均开销分母含 5 道负例。独立集 160 万像素下 11 道由失败变成功，1 道由成功变失败，双证据题由 1/8 到 3/8。260 万像素下救回 2 道、退化 3 道，双证据题由 6/8 到 5/8。116 条独立实验轨迹在 results/heldout.json，两份公开回归分别为 results/scan-public-images.json 和 results/scan-public.json。此前的结果文件用于追溯旧版本。

样本限于三份数字原生论文的栅格化页面和短语任务，未覆盖真实扫描设备产生的倾斜、污损、压缩与旋转，也未验证新来源上的数值提取。固定内缩可能裁掉页眉或边缘，整页补读也受剩余预算约束。OCR 像素只度量送给识别器的面积，端到端加速仍需计时实验。

## 学习工单

在 results/heldout.json 搜索 veld.pdf-2 和 1600000。旧策略截至整页补读仍未读到锚点。新策略先以 434×644 像素扫描正文，后在该页追加 focus:A 裁剪，定位到参考框。对照两条轨迹的 box 和 size，计算原页坐标怎样换算为每次 OCR 输入坐标。

练习。先解释为什么同等像素下裁剪会提高字符采样密度，再选一批带边注的页面验证固定边距的失败。参考答案是按观察图边长除以原裁剪边长来计算采样密度，原裁剪变小带来更大的每字像素数。涉及边注时应同时检查正文和边注两组的严格通过率，并记录实际增加的像素。
